LearnableMeta lets map creators attach one or more educational notes to a location. Players see the relevant notes after guessing.

<Aside type="note">
  The [Creator Dashboard](https://learnablemeta.com/map-making) requires signing in with Discord.
</Aside>

## Basic workflow

<Steps>

1. **Prepare the map in map-making.app.**

   Create or open your map in [map-making.app](https://map-making.app/). In **Map settings**, enable **Use Pano ID locations by default**.

   Every location must have a Pano ID before LearnableMeta can import it. Fix any older locations that do not have one before exporting.

2. **Tag the locations.**

   Give every location at least one tag. Reuse a tag on every location where the same clue applies. You can add multiple tags when one panorama teaches multiple clues.

   Read [Map JSON and tags](/map-creators/map-format/) for the recommended naming convention and multi-meta behavior.

3. **Export and publish the source map.**

   Export the locations JSON from map-making.app. In [GeoGuessr My Maps](https://www.geoguessr.com/me/maps), create a map with **Handpicked locations**, then publish the map-making.app locations using the Map Making Tools userscript workflow.

4. **Create a LearnableMeta map group.**

   Sign in to the [Creator Dashboard](https://learnablemeta.com/map-making) and create a group. A group can power one map or several related maps from the same uploaded locations.

5. **Upload the locations.**

   Open the group, choose **Upload Locations**, and upload the exported JSON. LearnableMeta creates a meta entry for each new tag.

6. **Write the explanations.**

   Open each meta and add its player-facing **Name** and **Note**. Notes support Markdown. Use **Note from Plonkit** when you used Plonk It descriptions or images so the source is credited automatically.

   **Footer** and **Levels** are optional. After saving the meta, use the **Images** tab to upload images—LearnableMeta resizes and compresses them automatically—or the **Map area** tab to add a [GeoJSON overlay](/map-creators/geojson-overlays/).

7. **Connect the GeoGuessr map.**

   Open the group's **Maps** tab and choose **Add Map**. Enter a name and the GeoGuessr ID—the long value after `/maps/` in the map URL. The remaining fields are optional for a basic setup.

8. **Publish LearnableMeta changes.**

   Return to **Metas** and choose **Sync UserScript**. Sync again after changing locations, notes, images, map areas, or map settings; players do not see unsynchronized changes.

</Steps>

For bulk editing, LearnableMeta also supports the [meta JSON upload format](/map-creators/meta-uploads/).
