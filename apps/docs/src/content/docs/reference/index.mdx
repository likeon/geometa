## Terminology

- **Meta:** A recognizable clue that can help identify a country or region in GeoGuessr.
- **Userscript:** The browser script that displays LearnableMeta notes inside GeoGuessr.
- **Location tag:** One of the internal labels connecting a map location to a meta. A location can have more than one.
- **Map group:** A set of related locations, metas, and published maps managed together in the Creator Dashboard.
- **Level:** A creator-defined grouping that can organize metas by difficulty or learning stage.
