title: Install on Android

import { Aside, Steps } from '@astrojs/starlight/components';

<Aside type="caution" title="Browser only">
  LearnableMeta does not run in the GeoGuessr Android app. Open GeoGuessr in Firefox for Android instead.
</Aside>

Firefox for Android supports the browser extensions needed to run LearnableMeta.

<Steps>

1. Install Firefox on your Android device.
2. In Firefox, install [Tampermonkey from Firefox Add-ons](https://addons.mozilla.org/firefox/addon/tampermonkey/).
3. Open the [LearnableMeta userscript installer](https://github.com/likeon/geometa/raw/main/dist/geometa.user.js) and confirm the installation.
4. Open a fresh GeoGuessr tab in Firefox and choose a [LearnableMeta map](https://learnablemeta.com/maps).

</Steps>

<Aside type="tip">
  The mobile experience works best on a tablet. GeoGuessr and the LearnableMeta hint panel can feel cramped on a phone-sized screen.
</Aside>
