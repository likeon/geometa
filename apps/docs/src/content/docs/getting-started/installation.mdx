## The common installation flow

<Steps>

1. Install a userscript manager supported by your browser.
2. Open the [LearnableMeta userscript installer](https://github.com/likeon/geometa/raw/main/dist/geometa.user.js).
3. Confirm the installation in your userscript manager.
4. Restart the browser or open a fresh tab.
5. Play one of the [LearnableMeta maps](https://learnablemeta.com/maps).

</Steps>

<Aside type="caution">
  The script will not load in tabs that were open before installation. Open a new GeoGuessr tab or restart your browser before testing it.
</Aside>

If the userscript downloads as a file instead of opening an installation window, follow the [manual installation video](https://www.youtube.com/watch?v=RpjvLpyiras).
