LearnableMeta teaches useful GeoGuessr clues while you play. Its maps contain tagged locations, and its browser userscript displays an explanation after each guess.

## What you need

- A GeoGuessr account
- A supported browser
- A userscript manager such as Tampermonkey
- The LearnableMeta userscript

## Install LearnableMeta

LearnableMeta runs as a userscript inside GeoGuessr. Choose your browser or device to install a supported userscript manager:

## Start learning

<Steps>

1. **Install a userscript manager.**

   Follow the guide for your browser or device above.

2. **Install LearnableMeta.**

   Open the [LearnableMeta userscript installer](https://github.com/likeon/geometa/raw/main/dist/geometa.user.js) and confirm the installation in your userscript manager.

3. **Open a fresh browser tab.**

   Tabs that were already open during installation may not load the userscript. Restarting the browser is the safest option.

4. **Choose a LearnableMeta map.**

   Browse the [available maps](https://learnablemeta.com/maps) and open one in GeoGuessr.

5. **Play and review each clue.**

   Make your guess normally. On the results screen, LearnableMeta shows the clue attached to that location.

</Steps>

<Aside type="caution">
  The script will not load in tabs that were open before installation. Open a new GeoGuessr tab or restart your browser before testing it.
</Aside>

If the userscript downloads as a file instead of opening an installation window, follow the [manual installation video](https://www.youtube.com/watch?v=RpjvLpyiras).
